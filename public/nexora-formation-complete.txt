# BIENVENUE

Vous n’avez pas acheté un simple PDF à lire.

Vous avez entre les mains un **système d’exécution**.

L’objectif de cette formation est de vous permettre de partir d’une situation simple :

* aucune audience ;
* aucun produit ;
* aucune expérience particulière dans la vente en ligne ;
* éventuellement un petit budget ;
* beaucoup d’informations contradictoires sur Internet ;

…et de construire progressivement une activité beaucoup plus structurée.

Deux parcours sont possibles.

## PARCOURS A — CRÉATEUR

Vous partez de zéro et construisez votre propre produit digital.

Vous allez apprendre à :

1. trouver un problème réel ;
2. vérifier qu’une demande existe ;
3. construire une solution ;
4. transformer cette solution en offre ;
5. créer votre page de vente ;
6. attirer vos premiers prospects ;
7. obtenir vos premières données commerciales ;
8. améliorer votre système.

## PARCOURS B — REVENDEUR MRR

Vous souhaitez commencer plus rapidement en commercialisant un produit dont la licence autorise la revente.

Vous allez apprendre à :

1. comprendre précisément vos droits ;
2. positionner l’offre ;
3. créer votre propre angle ;
4. construire votre page ;
5. créer du contenu ;
6. trouver des partenaires ;
7. réaliser votre premier cycle de lancement ;
8. améliorer progressivement votre avantage concurrentiel.

## PARCOURS C — HYBRIDE

Vous pouvez également commencer avec la revente pour apprendre la distribution, puis créer progressivement vos propres produits complémentaires.

C’est souvent une stratégie intéressante.

Vous apprenez d’abord à vendre.

Ensuite, les conversations avec vos clients révèlent les produits propriétaires qu’ils souhaitent réellement acheter.

# LA RÈGLE PRINCIPALE

Cette formation ne promet aucun revenu.

Un produit, une publicité ou une stratégie ne peut pas garantir une vente.

En revanche, vous allez disposer d’un processus dans lequel **chaque étape débouche sur une action et un résultat vérifiable**.

Trois principes vont revenir constamment.

## 1. PREUVE AVANT CRÉATION

Une idée ne mérite pas plusieurs semaines de travail avant d’avoir trouvé des signes que le problème existe.

## 2. OFFRE AVANT TRAFIC

Plus de visiteurs ne sauvera jamais une offre que personne ne comprend.

## 3. MESURE AVANT SCALE

Vous ne devez pas augmenter vos dépenses simplement parce qu’une campagne génère quelques ventes.

Vous devez comprendre :

* vos coûts ;
* votre marge ;
* votre conversion ;
* vos remboursements ;
* votre acquisition.

## UN PRODUIT DIGITAL N’EST PAS SIMPLEMENT DE L’INFORMATION

Internet contient déjà une quantité presque illimitée d’informations gratuites.

Un produit digital devient intéressant lorsqu’il permet au client de :

* gagner du temps ;
* éviter une erreur ;
* réduire une incertitude ;
* obtenir une méthode structurée ;
* prendre une décision ;
* produire un résultat ;
* suivre un processus plus facilement.

Votre produit ne doit donc pas simplement expliquer.

Il doit **faire avancer**.

# LES PRINCIPAUX FORMATS

## MINI-GUIDE / EBOOK

Idéal pour :

* expliquer une méthode simple ;
* résoudre un problème précis ;
* proposer un produit d’entrée.

Complexité : faible.

## TEMPLATE

Idéal lorsque le client cherche avant tout à gagner du temps.

Exemples :

* template Notion ;
* tableau Excel ;
* modèle Canva ;
* système de suivi ;
* documents prêts à personnaliser.

## PACK DE RESSOURCES

Plusieurs ressources regroupées autour d’un même problème.

Exemple :

Pack création TikTok :

* hooks ;
* scripts ;
* calendrier ;
* templates ;
* checklist.

## FORMATION

Adaptée lorsqu’une transformation nécessite plusieurs étapes.

## COMMUNAUTÉ

Intéressante lorsqu’une valeur nouvelle est délivrée régulièrement.

## SERVICE PRODUCTISÉ

Le client achète un résultat en partie réalisé pour lui.

Plus difficile à automatiser, mais généralement vendu plus cher.

## REVENTE MRR

Vous obtenez une licence vous autorisant à commercialiser un produit existant dans certaines conditions.

Votre travail principal devient alors :

* le positionnement ;
* la distribution ;
* le marketing ;
* l’expérience client.

# NE COMMENCEZ PAS PAR UNE NICHE

« Marketing »

n’est pas un problème.

« Fitness »

n’est pas un problème.

« Intelligence artificielle »

n’est pas un problème.

Ce sont des catégories.

Un problème exploitable ressemble davantage à :

> « Je publie régulièrement sur TikTok mais je ne sais pas comment transformer mes vues en visiteurs sur ma page. »

ou :

> « Je veux vendre un produit digital mais je ne sais pas quoi créer ni dans quel ordre commencer. »

Plus le problème est précis, plus l’offre peut être claire.

---

# LES TROIS CARACTÉRISTIQUES D’UN PROBLÈME INTÉRESSANT

Un problème devient particulièrement intéressant lorsqu’il est :

### FRÉQUENT

Il revient régulièrement.

### URGENT

La personne veut le résoudre rapidement.

### COÛTEUX

Il lui coûte :

* de l’argent ;
* du temps ;
* du stress ;
* des opportunités.

Deux critères sur trois peuvent déjà être suffisants.

---

# LES AVIS 3 ÉTOILES

Les avis moyens sont particulièrement intéressants.

Pourquoi ?

Un avis 1 étoile peut simplement venir d’un client très mécontent.

Un avis 5 étoiles contient souvent peu de détails.

Mais un avis 3 étoiles explique fréquemment :

> « Le produit était bien, mais… »

Le mot **mais** est précieux.

Il montre une amélioration potentielle.

---

# SCORE /35

Notez chaque idée de 1 à 5.

### DEMANDE

Le problème apparaît-il plusieurs fois ?

### URGENCE

La personne veut-elle réellement agir ?

### POUVOIR D’ACHAT

### PREUVE DE MARCHÉ

### DIFFÉRENCIATION

### ACCÈS

Sous 20 :

retravailler.

Entre 20 et 24 :

continuer les recherches.

24+ :

### ACTION

Puis complétez :

> **[Audience] veut [résultat], mais bloque à cause de [problème], malgré [solution déjà essayée].**

### CHECKPOINT

Votre idée doit être liée à des comportements observables.

Pas simplement :

> « Je pense que ça pourrait marcher. »

# MODULE 20 — COMPRENDRE LE MRR

## RÉSULTAT

Savoir exactement ce que vous pouvez commercialiser.

---

# MRR ≠ PROPRIÉTÉ TOTALE

Une licence MRR peut permettre de revendre un produit.

Cela ne signifie pas nécessairement que vous devenez son créateur original.

Le contrat détermine vos droits.

---

# DEUX MODÈLES

## RESALE RIGHTS

Vous vendez le produit.

Votre client peut l’utiliser.

Il ne peut pas nécessairement le revendre.

## MASTER RESELL RIGHTS

Lorsque la licence le prévoit explicitement :

vous pouvez vendre le produit à un client qui peut également recevoir le droit de revente.

---

# « 100 % DES REVENUS »

Une licence peut prévoir que le revendeur conserve **100 % du chiffre d’affaires qu’il encaisse sur ses propres ventes**.

Cela ne signifie pas :

* zéro frais ;
* zéro taxe ;
* propriété absolue ;
* aucune obligation envers le client.

Le revendeur reste responsable de :

* son activité ;
* ses paiements ;
* ses remboursements ;
* son support ;
* sa conformité.

---
