## ⚠️ 3 règles éliminatoires (avant tout autre critère)

1. **Entrepôt US.** Si "Ships from CN" ou "Global warehouse" seulement → **écarter**. Il faut voir "US warehouse", "USA", "United States" dans les shipping options. Zéro tolérance : le délai 2-8 jours annoncé aux clients ne fonctionne QUE depuis un entrepôt US.

2. **Propriété intellectuelle.** Aucun personnage sous licence : Disney, Marvel, DC, Nintendo, Star Wars, Harry Potter, Squid Game, Stranger Things, Wednesday, Beetlejuice, KPop Demon Hunters, Corpse Bride (Tim Burton). Aucun logo, aucune citation, aucune police reconnaissable. Le mot "Krampus" seul est libre (folklore Alpin domaine public) MAIS pas d'affiche film ni de citation Michael Dougherty 2015. Le mot "Nosferatu" seul est libre (Murnau 1922 domaine public) MAIS pas d'affiche du remake 2024.

3. **Conformité US.** Costumes : polyester (16 CFR 1610 friendly), pas de coton non traité. Adultes seulement — aucun costume enfant, aucun bébé. Masques : pas de peinture métallique inhalable, edges non-cutting. Party favors : mention "small parts, ages 3+" si applicable. Zéro FDA (pas de lentilles, pas de maquillage, pas de faux sang, pas de contact peau prolongé).

## Format de lecture

Chaque bloc te donne uniquement ce dont tu as besoin sur le moment : les termes de recherche à coller dans CJ, le plafond de coût rendu (produit + port supplier), le stock minimum, et 2-3 vérifications spécifiques. **Le coût rendu MAX est le seul chiffre à comparer** — si le total supplier + port dépasse, écarter. Rien d'autre à faire.

**⚠️ URLs CJ non fournies** — je ne connais pas le format exact des URLs de recherche du moteur CJ (il change souvent, dépend de la session, du filtre warehouse actif). Les termes sont à coller directement dans la barre de recherche CJ, avec le filtre "US Warehouse" activé en amont dans les filtres de gauche.

## Après validation : que faire

Pour chaque fiche validée :
1. Noter le **SKU CJ exact** trouvé (format `CJ...`)
2. Coller SKU dans la fiche Shopify DRAFT correspondante (metafield `sku_supplier` ou variant SKU)
3. Retirer le tag `internal:awaiting-supplier-verification`
4. Ajouter le tag `supplier:cj-verified`
5. Confirmer stock actuel warehouse US (compter → renseigner)
6. Basculer status DRAFT → ACTIVE seulement à réception de photos correctes 2000×2500

Pour chaque fiche rejetée :
1. Documenter dans HUMAN-INPUT-NEEDED.md : nom produit + raison précise (IP / non-US warehouse / cost dépassé / qualité)
2. Optionnel : chercher alternative avec un autre pattern de recherche
3. Si rejet définitif : supprimer la fiche Shopify DRAFT (`productDelete`)
