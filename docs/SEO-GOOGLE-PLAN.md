## Principe fondateur — DOUBLE TITRAGE

Deux titres par produit, deux fonctions distinctes :

**(a) Titre affiché** — voix The Manor, lu par le client, forme le premier impact sur la page produit. Style éditorial, jamais keyword-stuffé.

**(b) Meta title SEO** — ≤ 60 caractères, écrit pour le moteur, jamais vu par le client (sauf via SERP Google). Format strict :

```
[Type] + [Style] + Halloween + [Produit] + [Caractéristique]
```

Exemple concret :
- (a) *The Watcher — 11.8ft Giant Inflatable Ghost with Flames & LED Eyes*
- (b) *Giant Halloween Inflatable Ghost 11.8ft Yard Decor · LED Eyes*  (58 char ✓)

**Règle inviolable** : ne dégrade JAMAIS le (a) pour du SEO. Si un mot-clé ne peut pas s'insérer sans casser la voix, il va dans la meta description ou dans le corps de la page, pas dans le titre.

---

## Angle différenciant à pousser en priorité

**Décoration extérieure grand format.** C'est notre seul angle où on n'est pas en concurrence frontale avec les boutiques de déguisements génériques ou les Amazon FBA sur les accessoires plastique. Les gonflables 9-12 ft ont peu d'acteurs sérieux sur SEO US en dropshipping — le pack est dominé par Home Depot / Lowe's / Wayfair / Target sur la marque mais reste ouvert sur la longue traîne.

Cibles SEO prioritaires :
- `giant halloween inflatable` (volume élevé, concurrence institutionnelle mais pas dropship)
- `12 foot halloween inflatable ghost` / `11 ft giant ghost decoration` (long-tail commercial)
- `halloween skeleton banner yard sign` (niche, banner spécifique)
- `giant stacked pumpkins inflatable` (long-tail, catégorie émergente)
- `outdoor halloween yard decorations kit` (bundle-oriented)

Cibles à laisser aux gros :
- `halloween decorations` (massif générique, on ne peut pas rank)
- `halloween costume` (rank impossible pour un nouveau site)

## Schema.org structured data — à intégrer product.liquid custom (Session 6)

Prochaine session thème, ajouter le JSON-LD Product schema dans le template product custom :
- `@type: Product`
- name, description, image, sku, brand, mpn (SKU CJ), gtin (n/a → identifier_exists false)
- `offers` avec price, priceCurrency USD, availability, shippingDetails
- `aggregateRating` seulement quand vraies reviews existent (pas de fake)
- BreadcrumbList sur toutes pages
- Organization schema en layout head

Sans ces éléments, Google Merchant + Rich Results ne passent pas correctement le catalogue.

1. Boutique doit être publique (retirer password protection)
2. Créer compte GMC, valider domain via Shopify (natif Google & YouTube Sales Channel app)

4. Feed auto via Shopify → Google Merchant Sales Channel app
5. Vérifier statut des 14 produits dans Diagnostics — s'attendre à warnings sur images 600×600 (sous seuil recommandé Google 800px). **À résoudre** avec nouveaux visuels 2000×2500 arrivant demain.
