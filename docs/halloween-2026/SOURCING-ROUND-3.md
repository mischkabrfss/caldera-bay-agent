**Traduction pratique :**
- **$12.99–$19.99** : très serré. Le profit $10 n'est pas atteignable — ces produits ne peuvent exister qu'en tant que **composants de bundle**, jamais standalone à cette échelle. Considérer $19.99 comme minimum réaliste pour standalone.
- **$22.99–$27.99** : la fourchette d'or. Profit + marge tiennent.
- **$29.99** : uniquement pour produits dont le C rendu ≤ $12 (rare chez CJ à cause du port fixe).
- **$32.99–$34.99** : confortable, C max $14.

**Contrainte structurelle CJ** : le port US ~$5-7 fixe même sur un produit à $2. Donc pour tenir C ≤ $10 il faut un produit à ~$3-5 max supplier + $5-7 port. Vérifier ce ratio pour chaque candidat.

## Impact projeté sur l'assortiment

### AOV révisé (avec gamme d'entrée intégrée)

- 20 % achat mono gamme d'entrée ($15-35) → moy $23
- 20 % achat mono inflatable → moy $107

Baisse vs V4 ($143.55) MAIS **volumes attendus 2-3× plus élevés** grâce au ticket d'entrée accessible + free ship activé. Trade-off assumé.

### Impact seuil free shipping $65

**Avant Round 3** : le seuil ne se déclenche que pour les gonflables ($90+), les bundles ($180+), et le blanket ($110). Autrement : tout achat POD + accessoire = flat $6.95. Le seuil ne servait à rien pour les paniers < $65 (majoritaires si gamme d'entrée existe).

**Après Round 3** : le seuil devient réellement incitatif. Exemples :
- Panier Tea Lights $16.99 → flat $6.95 (client paie $23.94)
- Panier Tea Lights + Mug $16.99 + $22.99 = **$39.98** → flat $6.95 (encore sous seuil)
- Panier Tea Lights + Mug + Candy Bowl $16.99 + $22.99 + $24.99 = **$64.97** → **1 cent sous seuil**. Trigger d'ajout urgentissime.
- Panier + n'importe quel 4e item → **$65+ = free ship**. Save $6.95.

**Le seuil $65 est désormais un vrai levier AOV.** Recommandation : garder tel quel, ne pas modifier.
